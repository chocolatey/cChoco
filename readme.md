# Community Chocolatey DSC Resource (AKA cChoco)

cChoco has now been archived, and will not have any further updates or support. Please see this [GitHub issue](https://github.com/chocolatey/cChoco/issues/192) for more information.

Instead of using cChoco to manage Chocolatey packages via Desired State Configuration (DSC), we recommend using [Chocolatey Module](https://github.com/chocolatey-community/Chocolatey-Module). There are migration examples available in the [wiki](https://github.com/chocolatey/cChoco/wiki).
